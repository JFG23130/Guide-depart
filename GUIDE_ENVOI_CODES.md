## 🎯 Meilleures méthodes d'envoi (par ordre de préférence)

### 1️⃣ **Messagerie Airbnb** ⭐ RECOMMANDÉ

**✅ Avantages:**

- Intégré à la plateforme
- Historique de conversation préservé
- Pas besoin de numéro de téléphone
- Traçabilité complète
- Pas de coût supplémentaire

**📝 Template:**

```

Nous sommes ravis de vous accueillir à Katikias 33! 🏡

🔐 Votre code d'accès personnel:
{{CODE}}

✅ Informations pratiques
✅ Recommandations locales
```

1. Ouvrir Airbnb Hôte

4. Copier-coller le template
5. Remplacer {{variables}} par les vraies valeurs

### 2️⃣ **WhatsApp** ⭐ TRÈS EFFICACE

**✅ Avantages:**

- Confirmation de lecture
- Rapide et direct
- Médias riches (QR code possible)
- International sans frais
- Taux d'ouverture ~98%

**📝 Template court:**

```
Bonjour {{Nom}} 👋

Votre code d'accès Katikias 33:
🔐 {{CODE}}

📱 Guide complet:
{{LIEN}}

✅ WiFi, portail, arrivée, tout y est!

À bientôt! 🏡
```

**🚀 Comment envoyer:**

```
https://wa.me/{{PHONE}}?text=Bonjour%20{{NOM}}%20%F0%9F%91%8B%0A%0AVotre%20code%20d%27acc%C3%A8s%20Katikias%2033%3A%0A%F0%9F%94%90%20{{CODE}}%0A%0A%F0%9F%93%B1%20Guide%20complet%3A%0A{{LIEN}}
```

**Formats de téléphone acceptés:**

- `+33612345678` (France)
- `+41774316962` (Suisse)
- `+353863836448` (Irlande)
- `+4917684535352` (Allemagne)
- `+31618194155` (Pays-Bas)

### 3️⃣ **SMS** ⚠️ LIMITÉ

**✅ Avantages:**

- Universel (tous les téléphones)
- Pas besoin d'application
- Bon taux d'ouverture

**❌ Inconvénients:**

- Coût par SMS (surtout international)
- Limite de caractères (160)
- Pas de confirmation de lecture
- Pas de médias riches

**📝 Template ultra-court (< 160 caractères):**

```
Katikias33: Code {{CODE}}
Guide: {{LIEN}}
```

**🚀 Services SMS recommandés:**

- **Twilio** - 0.05€/SMS international
- **OVH SMS** - Tarifs français avantageux
- **Airbnb SMS** - Intégré (si activé)

## 💡 Bonnes pratiques

### ✅ À FAIRE

1. **Personnaliser le message**
   - Utiliser le prénom de l'invité
   - Mentionner les dates exactes
   - Ajouter une touche personnelle

2. **Timing optimal**
   - J-7: Premier envoi (Airbnb + WhatsApp)
   - J-3: Relance si pas de lecture
   - J-1: Rappel final si nécessaire

3. **Multi-canal**
   - Airbnb (principal)
   - WhatsApp (confirmation)
   - SMS (backup)

4. **Suivi**
   - Noter qui a reçu/lu
   - Relancer les non-lecteurs
   - Confirmer la réception

### ❌ À ÉVITER

1. **Spammer**
   - Pas plus de 2-3 messages
   - Espacer les envois

2. **SMS internationaux inutiles**
   - Préférer WhatsApp (gratuit)
   - Sauf si pas d'accès Internet

3. **Emails seuls**
   - Risque de spam
   - Taux d'ouverture faible

4. **Oublier le suivi**
   - Vérifier les lectures
   - Relancer si besoin
