# 📸 Instructions pour ajouter l'image de la télécommande

## Étape 1 : Ajouter l'image

1. Trouvez l'image de la télécommande Somfy sur votre ordinateur
2. Renommez-la : `telecommande_somfy.png` (ou .jpg)
3. Copiez l'image dans le dossier : `C:\Users\jfgir\Dev\Airbnb\Guide-depart\`

## Étape 2 : Vérification

L'image doit être accessible à l'adresse :
```
https://jfg23130.github.io/Guide-depart/telecommande_somfy.png
```

## Format recommandé

- **Format** : PNG ou JPG
- **Taille** : Max 500 x 500 pixels
- **Poids** : Moins de 200 KB pour un chargement rapide

## Note

Si vous n'avez pas l'image, la page fonctionnera sans mais l'image ne s'affichera pas. 
Vous pouvez ajouter l'image plus tard, elle s'affichera automatiquement.
