🏖️ Procédure de Départ

Katikias 33 - Merci de votre séjour !

  1. 🧺 Rassembler les serviettes sales

    Mettre toutes les serviettes utilisées dans le panier prévu à cet effet dans la salle de bain.

  2. 🗑️ Jeter les ordures

    Les conteneurs se trouvent à côté de l'entrée piscine :

    • Poubelle générale (sac noir)
    • Poubelle recyclage (sac jaune)
    • Vider tous les petits paniers de la maison

  3. 💡 Éteindre les lumières et les appareils

    • Éteindre toutes les lumières intérieures et extérieures
    • Couper le chauffage/climatisation
    • Débrancher les appareils non essentiels
    • Éteindre la télévision et les écrans

  4. 🔒 Tout verrouiller

    • Replier le store de la piscine
    • Fermer toutes les baies vitrées
    • Baisser tous les volets
    • Vérifier que toutes les portes sont fermées

  5. 🗝️ Rendre les clés

    • Poser les clés de la maison sur la table du salon
    • Poser le bracelet piscine à côté des clés
    • Fermer la porte d'entrée en partant

  6. 📝 Informer votre hôte

    Envoyez un message via Airbnb ou appelez pour confirmer votre départ.
