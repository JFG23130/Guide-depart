💡 ASTUCES AVANCÉES

Importer depuis plusieurs sources:
```python
from import_from_airbnb_emails import QuickImport

# Depuis texte copié
manager = QuickImport.from_text("""
Code: KATI0101
Nom: Jean Dupont
Arrivée: 2026-01-10
Départ: 2026-01-15
WiFi: Katikias33
Portail: 9999
---
Code: KATI0102
...
""")
manager.export_to_csv()
```

Lister codes actifs aujourd'hui:
```bash
python csv_to_codes_config_optimized.py
# Affiche automatiquement codes actifs/expirés
```

Gérer QR codes:
```bash
# Liste tous les QR codes
python qrcode_manager.py list

# Health check
python qrcode_manager.py health

# Générer documentation
python qrcode_manager.py docs
```
